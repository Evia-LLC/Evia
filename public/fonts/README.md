# Fonts

The design typefaces, self-hosted so the app contacts no third party before
cookie consent. Latin subsets of Google Fonts' woff2 builds (downloaded
25 September 2026 with the Founder's approval), each under the SIL Open Font
License 1.1 — licence texts alongside:

| File | Family | Licence |
|---|---|---|
| `google-sans-flex-latin.woff2` | Google Sans Flex (opsz, wght 300–700) | `OFL-GoogleSansFlex.txt` |
| `newsreader-latin.woff2` | Newsreader roman (opsz, wght 300–600) | `OFL-Newsreader.txt` |
| `newsreader-italic-latin.woff2` | Newsreader italic (opsz, wght 300–600) | `OFL-Newsreader.txt` |
| `oooh-baby-latin.woff2` | Oooh Baby | `OFL-OoohBaby.txt` |

`@font-face` rules live at the top of `src/styles/tokens.css`.
