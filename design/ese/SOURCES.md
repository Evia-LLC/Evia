# Asset provenance

## Base humanoid, face textures, rig and facial morphs

- Source asset: `avatars/mpfb.glb` in [met4citizen/TalkingHead](https://github.com/met4citizen/TalkingHead).
- Direct repository asset: [mpfb.glb](https://github.com/met4citizen/TalkingHead/blob/main/avatars/mpfb.glb).
- License declaration: the [TalkingHead README](https://github.com/met4citizen/TalkingHead#installation) identifies the example MPFB avatar as **CC0**. A copy of the relevant declaration is preserved below.
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
- Tools used by its author: Blender and MPFB/MakeHuman.

The source README states: “The avatar is licensed under CC0.” This is the asset-specific declaration for `mpfb.glb`; the repository's JavaScript code license is separate.

The preceding `outputs/blender/character/elohim.blend` is the project's edited version of that CC0 base, retaining its 67-joint rig and facial morphs. Ese continues from that source.

## Project-authored additions

The gathered blonde hairstyle, broad locks and strands, open lab coat shell, lapels, shoulder overlap pieces, neckline insert, jewelry, infinity emblem, materials, blue iris recolouring, facial refinements, and eight body gesture clips were generated/edited in Blender for this project. No purchased marketplace assets were used. The reference screenshot was supplied by the user as art direction and is not embedded in the model.

All character surfaces in `ese.glb` are three-dimensional meshes. The room, portal, film, synthetic demonstration client, voice and application code are separate assets with their own provenance.
